# 온기지도 기획 보고서

2026년 11월 27일 · Codex Community Hackathon – Seoul · 기획 및 인수 기준. [행사 안내](https://luma.com/p8l79x8m)

## 문제와 대상

이웃에게 도움을 받은 사람은 감사의 이야기를 사건이 일어난 지역과 함께 남기고 싶다. 동네를 오가거나 새로 이사한 사람은 관심 지역에서 있었던 도움과 회복의 사례를 짧게 읽고 싶다. 온기지도는 글쓰기에서 게시 기준을 적용하고, 읽기에서는 지역을 선택해 바로 해당 글을 만날 수 있게 한다. 이는 시연으로 검토할 제품 가설이며, 이용자 조사나 사회적 효과 측정은 진행 전이다.

## 시연에서 경험하는 흐름

| 사용자 | 흐름 | 확인할 결과 |
| --- | --- | --- |
| 휴대전화 방문자 | 공개 주소 → 홈의 최신·인기 카드 → 16개 지역 지도 → 지역 피드 | 로그인 없이 둘러볼 수 있다. 글이 없는 지역도 타일을 눌러 빈 상태를 확인할 수 있다. |
| 예시 화면을 둘러보는 방문자 | 홈 → 알림 → 프로필 → 지역별 소식 → 대화 | 첫 화면에 읽기 전용 시연임을 표시한다. 예시 알림·프로필·대화는 열 수 있고 게시·공감·읽음·전송·초기화에 해당하는 쓰기는 발생하지 않는다. |
| 이웃에게 도움을 받은 작성자 | 로컬 실행 → 제목·본문·사건 발생 광역 지역 입력 → Codex 심사 → 지역 피드와 지도 확인 | 승인된 발행 결과가 지역 피드에 한 번 나타나고 집계 조건을 충족하면 지도에 즉시 반영된다. |
| 글을 수정하는 작성자 | 차단·보류·연결 실패 안내 → 입력 확인 또는 수정 → 재시도 | 세 입력을 유지하고 새 승인이 나오기 전까지 피드·인기 목록·지도 집계에 추가하지 않는다. |

홈의 최신·인기 미리보기는 각 최대 3개다. 최신은 작성시각 내림차순이다. 인기는 오늘을 포함한 최근 7개 한국 표준시(KST) 날짜의 글을 공감 수 내림차순, 작성시각 내림차순, ID 오름차순으로 정렬한다. 로컬에서 게시·공감·알림 읽음·예시 대화 입력을 브라우저에 저장하며 초기화로 예시 상태를 다시 불러올 수 있다. 지역은 작성자가 직접 선택한다.

## 게시 기준과 데이터 경계

작성 화면에서 브라우저 저장 위치와 심사를 위해 Codex에 전달하는 제목·본문을 고지한다. `APPROVED`는 제출한 제목과 본문이 온기지도의 게시 기준을 충족했다는 뜻이다. 사건의 발생 여부와 내용의 정확성은 별도 검증 범위다.

| 상태 | 조건과 동작 |
| --- | --- |
| 승인 `APPROVED` | 도움·감사·회복·연대가 이야기의 중심인 글. 침수처럼 어려운 사건 뒤 이웃의 도움을 받은 글도 해당한다. 제출 순간의 제목·본문·지역을 한 번만 저장한다. |
| 차단 `BLOCKED` | 비판·불만·비난·조롱·불안 조장이 중심인 글. 우호적인 끝맺음이 있어도 공격이나 타인 개인정보 노출이 있으면 차단한다. |
| 보류 `HOLD` | 풍자나 인용 등에서 작성 의도를 판단하기 어려운 글. 작성자가 맥락을 보완해 다시 요청할 수 있다. |
| 심사 불가 `UNAVAILABLE` | CLI 실행 실패·시간 초과·응답 검증 실패 등. 입력을 유지하고 다시 요청할 수 있게 한다. |

로컬 브리지는 같은 출처에서 제출한 요청만 받아 고정된 Codex 명령에 제목·본문을 JSON 표준 입력으로 전달한다. 심사 실행은 도구와 웹이 꺼진 읽기 전용 임시 작업 환경을 사용하며 동시 실행을 한 건으로 제한한다. 최대 대기 시간은 45초다. 공개 빌드는 읽기 전용 정적 앱이다.

## 지도의 산식과 해석

지도는 2026년 10월의 16개 광역 행정구역을 표시한다. 전남광주통합특별시는 한 타일이다. 분모는 같은 달 말 주민등록 인구로, 외국인은 집계 대상에서 제외된다. 지도 타일 위치는 krmap의 16개 네모 타일 배치를 따른다. [행정안전부 주민등록 인구 월간현황](https://jumin.mois.go.kr/statMonth.do) · [지도 원본 및 월간 CSV](../NOTICE.md)

1. 날짜는 오늘을 포함한 최근 7개 KST 날짜로 잡고, 시각이 잘못됐거나 미래인 글을 제외한다. 예를 들어 시연 당일 11월 27일에는 11월 21일 00:00 KST부터 현재까지다.
2. 공개 예시 글과 승인 후 발행된 글을 지역별로 집계한다. 같은 작성자가 같은 지역과 KST 날짜에 올린 글은 한 건으로 센다. 공감 수는 인기 목록에 사용한다.
3. 고유 작성자가 3명 이상이고 인구가 양수이면 `100,000 × 집계 건수 ÷ 주민등록 인구`를 소수 둘째 자리 이상으로 표시한다. 작성자가 3명 미만이면 ‘표본 부족’을 표시하며 타일은 계속 열 수 있다.

인구 보정은 규모가 다른 지역의 단순 건수를 공통 단위로 환산하기 위한 것이다. 서로 다른 작성자 세 명의 글을 한 건씩 집계하면 2026년 10월 인구 기준 세종은 0.77, 경기는 0.02다. 작은 분모에서는 글 한 건의 변화가 더 크게 보인다. 표본 기준은 표시 조건이며, 시연 데이터와 자발적으로 제출된 글에는 참여 편향이 있다. 지표는 앱에서 집계한 게시 활동을 나타내며 주민 성향과 지역의 우열을 평가하는 데 사용할 수 없다. [행정안전부 주민등록 인구 월간현황](https://jumin.mois.go.kr/statMonth.do)

## 검증 기준

아래는 통합본에서 재현할 인수 기준이다. 합성 입력을 사용하고 앱 버전·실행 경로·관측 결과를 함께 기록한다.

| 항목 | 통과 기준 | 확인 방법 |
| --- | --- | --- |
| 공개 탐색 | Safari에서 5개 탭과 예시 콘텐츠를 열고, 16개 타일 각각이 해당 피드로 이동한다. | 첫 화면에서 읽기 전용 안내를 찾고 탭·타일을 순서대로 선택한다. 글이 없는 지역에서 빈 상태도 확인한다. |
| 공개 상태 보호 | 게시·공감·읽음·전송·초기화로 인한 상태 쓰기 0건, 심사 요청 0건. | 공개본의 탐색과 가능한 조작 전후 및 새로고침 뒤 상태·브라우저 저장소·네트워크를 비교한다. |
| 판정 일치 | 침수 뒤 감사와 감사 맥락이 분명한 인용은 승인, 감사로 끝나는 집단 모욕과 합성 연락처 노출은 차단, 맥락이 부족한 인용은 보류를 기대한다. | 로컬 브리지로 각각을 제출해 실제 판정과 UI 상태를 기록한다. |
| 실패 복구와 중복 | 차단·보류·통제한 심사 실패 직후 입력 유지. 직후와 새로고침 뒤 피드·지도에 반영된 새 글 0건. 복구 후 승인된 제출 스냅샷 1건. | 실제 판정과 통제한 실패를 각각 기록한다. 연속 클릭과 심사 대기 중 입력 변경 시도를 각각 재현해 제출 시점의 제목·본문·지역이 한 번만 저장되는지 확인한다. |
| 지도 검산 | 작성자 2명이면 표본 부족, 같은 작성자·같은 날짜 중복과 미래 글 제외. 서울에서 세 작성자의 집계에 네 번째 작성자의 승인 1건을 더하면 표시 예가 0.03에서 0.04로 변한다. | KST 날짜 경계와 산식을 고정 시각 테스트에서 확인하고, 서울 게시 전후를 지도와 지역 피드에서 비교한다. |

사용성의 초기 검토는 첫 방문자가 도움 없이 홈에서 지역 글로 이동하고, 지도에 표시된 수치의 기간·단위·표본 기준을 설명할 수 있는지 관찰하는 방식이다. 행사 시연의 통과 여부로 지속 사용률이나 공동체 효과를 추정하지 않는다.
